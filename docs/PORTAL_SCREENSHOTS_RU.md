# Скриншоты портала release-readiness v0.1

Скриншоты предназначены для публичной демонстрации и экспертной оценки. Они
сняты на обезличенных mock data с реальным frontend-кодом портала.

Правило: screenshots не должны содержать live domains, private IPs,
пользовательские ФИО, live case IDs, runtime evidence paths или реальные
forensic hashes.

## Повторная генерация

Скриншоты можно переснимать только на demo/mock данных или на специально
обезличенном стенде. Live commercial AWatch-rus contour не использовать как
источник публичных PNG без отдельной ручной проверки приватности.
