# TASK 005: Rust Agent Baseline

## Цель

Закрепить Rust Agent как основной агентный baseline для регулярного сбора
данных AWatch-rus.

## Объем

- Проверка стабильности Windows runtime.
- Проверка публикации worktime/session telemetry.
- Проверка spool/retry поведения.
- Документирование rollback-пути на случай отказа.

## Ограничения

- Не переписывать стабильные вспомогательные компоненты только ради языка.
- Не ломать существующие Windows deployment-пакеты.
- Не добавлять неподтвержденные платформенные claims.

## Результат

Rust Agent используется как основной агентный слой там, где он уже проверен, а
границы поддержки описаны честно.
